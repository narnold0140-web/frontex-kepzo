# Határőr Akadémia – Frontex felkészítő

Telepíthető webapp a Frontex tudásteszthez (50 kérdés, 35 perc, félpontos levonás): gyakorló modulok, villámkör, vizsgaszimuláció, hibajavítás, rangok és XP.

Megnyitás: https://narnold0140-web.github.io/frontex-kepzo/
iPhone-on: Safari → Megosztás → Főképernyőhöz adás.
